## 핵심 발견 (현재 자동화의 구조적 한계)
- **broadcast는 TTY 스푸핑 방식**: `printf > /dev/ttysNN`는 셸 입력 라인 에디터를 거치지 않고 PTY에 직접 바이트를 주입한다. 멀티라인/특수키/vim 등 raw 모드 앱에서 깨질 수 있고, "어느 창에 보낼지" 선택(그룹핑)이 없다 — 현재 사용자의 **모든** TTY에 일괄 전송뿐. kitty/iTerm2/tmux는 "패널 그룹/세션 단위" 브로드캐스트를 제공.
- **세션 복원 부재**: ssht로 연 창이나 일반 작업 레이아웃(창/탭/분할 + cwd + 실행 중이던 커맨드)을 저장·복구하는 자동화가 없다. ghostty는 `window-save-state`/세션 복원 옵션이 있으나 "명명된 작업 세션(named layout) 저장→복원" 워크플로우는 미구현.
- **트리거 액션이 3종으로 고정**: `notify`/`bell`/`run`만 있고 **알림 라우팅**(텔레그램/Slack/ntfy 등 원격 채널)이 없다. 자리를 비웠을 때 데스크톱 알림은 무의미 — 이 프로젝트엔 이미 telegram MCP 연동이 있으므로 라우팅 대상이 명확.
- **트리거 매칭이 단순 glob + 종료코드**: 소요 시간 임계값(예: 30s 이상만 알림), 출력 내용 매칭(stderr에 "error" 포함 시), 디바운스가 없다. 짧은 `npm` 실행에도 알림이 떠 노이즈가 됨.
- **ssht 탭 모드가 깨지기 쉬움**: AppleScript `keystroke`로 SSH 커맨드를 타이핑 → 접근성 권한·딜레이(0.3s)·키보드 레이아웃에 취약. 비밀번호/특수문자 호스트에서 오타 위험.

## 이 툴킷에 추가할 제안 (우선순위순)
1. **[높음] 알림 라우팅 백엔드 — triggers `notify`를 멀티채널로 확장**
   - 무엇을/왜: `notify` 액션이 데스크톱 외에 telegram/ntfy로도 발송. 자리를 비운 상태에서 장기 빌드/에러를 폰으로 받음(이 프로젝트의 핵심 가치 "자리 비워도 알림"의 실현).
   - 구현 파일: `triggers` 포맷 확장(`notify:telegram [제목]`) + zsh-integration의 트리거 디스패처에 채널 분기 추가. telegram은 기존 MCP/봇 토큰 재사용.
   - 난이도: 중. Ghostty 네이티브 불가(셸 후크 영역) — 기존 스크립트 확장.
2. **[높음] 트리거 조건 고도화 — 소요시간 임계 + 출력 매칭 + 디바운스**
   - 무엇을/왜: `cmd:npm* notify` 대신 `cmd:npm* notify if>30s`처럼 오래 걸린 것만 알림. 노이즈 제거가 발견 시스템 신뢰도를 좌우.
   - 구현 파일: `triggers` 파서(zsh-integration의 preexec/precmd)에서 명령 시작 시각 기록→precmd에서 elapsed 비교. line-timestamps가 이미 elapsed를 계산하므로 재사용.
   - 난이도: 중. 기존 line-timestamp 로직 확장.
3. **[중간] 명명된 세션 저장/복원 — `ghostty-session save/restore <name>`**
   - 무엇을/왜: 현재 창/탭/분할 + 각 cwd를 JSON으로 저장하고 `open -na`로 재현. "프로젝트 작업 레이아웃"을 1커맨드로 부팅.
   - 구현 파일: 신규 `scripts/ghostty-session`. 레이아웃 수집은 ghostty의 IPC/CLI 한계로 cwd+창 목록 수준부터 시작(완전 분할 복원은 ghostty 네이티브 지원 확인 필요 → 다음 사이클 조사).
   - 난이도: 중~상. 부분적으로만 네이티브 가능.
4. **[중간] broadcast 그룹/세션 단위 타겟팅**
   - 무엇을/왜: 모든 TTY가 아니라 "그룹 N에 속한 창"에만 전송. kubectl 멀티클러스터/멀티서버 작업 시 안전.
   - 구현 파일: `ghostty-broadcast` 확장(`--group prod`로 sender 파일에 그룹 라벨, TTY→그룹 매핑 `/tmp/ghostty-bcast-group-*`).
   - 난이도: 중. 기존 스크립트 확장.
5. **[낮음] ssht 탭 모드 keystroke 제거**
   - 무엇을/왜: AppleScript 타이핑 대신 새 탭에서 SSH를 직접 `-e`로 실행하도록 ghostty CLI 옵션 재조사. 접근성 권한 의존 제거.
   - 구현 파일: `ssht`. ghostty의 새 탭 생성 CLI/IPC 지원 여부 확인 필요(다음 사이클).
   - 난이도: 낮~중. 네이티브 지원 여부에 좌우.
