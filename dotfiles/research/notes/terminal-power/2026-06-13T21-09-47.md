## 핵심 발견 (경쟁 터미널 파워 기능 vs 이 툴킷)

### kitty
- **kitty graphics protocol** — 터미널에 인라인 이미지 표시. Ghostty도 kitty graphics를 네이티브 지원(`icat`/chafa/timg로 표시 가능). → 툴킷에 "이미지 미리보기" 헬퍼 없음. **gap**. [웹검증 필요: Ghostty kitty-graphics 지원 범위]
- **kitty hints (`kitten hints`)** — 화면의 URL/경로/해시/IP를 키 입력으로 선택·복사·열기. Ghostty엔 동등 네이티브 없음 → zsh/스크립트 재현 어려움(화면 스캔 필요). **gap, 난이도 높음**.
- **remote control (`kitty @`)** — 소켓으로 창/탭 제어, 텍스트 주입. ghostty-broadcast가 TTY write로 부분 대체하나 구조적 제어는 없음.

### WezTerm
- **내장 멀티플렉서** — tmux 없이 분할/탭/세션 영속. Ghostty는 `window-save-state`로 세션 복원만(draft에 이미 후보). 멀티플렉싱은 Ghostty 네이티브 split로 충분.
- **command palette / launcher menu** — fuzzy 액션 검색. Ghostty엔 동등 기능 미확인. **gap** [웹검증 필요].
- **quick select mode** — kitty hints와 유사한 정규식 텍스트 선택.

### iTerm2
- **Shell Integration 마크 / 프롬프트 점프** — Ghostty는 `jump_to_prompt` 네이티브 보유(draft 확인). 이미 커버.
- **Triggers (정규식 → 액션)** — 툴킷 triggers와 유사하나 iTerm2는 출력 *내용* 정규식 매칭. 현 triggers는 cmd/exit만. **gap: 출력 패턴 매칭**.
- **Captured Output / Smart Selection** — 출력에서 패턴 추출. zsh 후크로 부분 재현 가능.
- **Password Manager / 자동 입력** — 보안 민감, 범위 외.

### Warp
- **Blocks (커맨드+출력 묶음)** — 블록 단위 복사/공유/네비게이션. Ghostty shell integration의 prompt 마크로 부분 재현 가능. 블록 복사 헬퍼 **gap**.
- **AI command search / Workflows** — Warp Workflows = 파라미터화된 커맨드 스니펫 런처. 툴킷에 스니펫/워크플로 런처 **없음**. **gap, fzf로 재현 쉬움**.
- **Notebooks** — 범위 외.

## 이 툴킷에 추가할 제안 (우선순위순)

1. **[높음] 커맨드 스니펫/워크플로 런처** — Warp Workflows 대응.
   - 무엇/왜: 자주 쓰는 파라미터화 커맨드(`kubectl`, `docker`, ssh 조합)를 yaml/txt로 저장하고 `fzf`로 검색·삽입. 1인 운영자의 반복 커맨드 마찰 제거.
   - 구현: `scripts/ghostty-workflow` (fzf + 스니펫 디렉토리) + `zsh-integration.zsh`에 ZLE 위젯(키바인드로 호출 → 커맨드라인 삽입).
   - 난이도: **낮음**. 스크립트로 완결. Ghostty 의존 없음(fzf만).

2. **[높음] 출력 내용 기반 triggers** — iTerm2 Triggers 대응.
   - 무엇/왜: 현 triggers는 cmd glob/exit code만. 출력에 `ERROR`/`panic`/특정 정규식 등장 시 알림·하이라이트. 장시간 빌드/배포 모니터링에 유용.
   - 구현: `zsh-integration.zsh` preexec/출력 캡처는 어려움 → `triggers` 파일에 `out:<regex>` 문법 추가하고 명령 출력을 tee로 스캔하는 래퍼. 난이도: **중간** (출력 캡처가 까다로움, PTY 전체 출력 후킹 한계).

3. **[중간] 인라인 이미지 미리보기 헬퍼** — kitty graphics 대응.
   - 무엇/왜: Ghostty가 kitty graphics 네이티브 지원 시 `icat`/chafa 래퍼로 이미지/PDF 썸네일을 터미널에 표시. img-paste와 시너지.
   - 구현: `scripts/ghostty-icat` (chafa/timg 우선 탐지 → fallback). 난이도: **낮음~중간** [웹검증 필요: Ghostty kitty-graphics placement 지원].

4. **[중간] URL/경로 hints 선택기** — kitty hints / Warp quick-select 대응.
   - 무엇/왜: 화면의 URL/파일경로/git hash를 키로 선택해 복사·열기. 마우스 없이 빠른 추출.
   - 구현: Ghostty 네이티브 미지원으로 추정 → tmux 없이는 어려움. scrollback을 `write_screen_file`로 덤프 후 fzf로 grep·선택하는 우회 가능. 난이도: **높음** (실시간 오버레이 불가, 덤프 기반 우회만).

5. **[낮음] 커맨드 블록 복사** — Warp Blocks 대응.
   - 무엇/왜: 직전 커맨드+출력을 한 번에 클립보드 복사(이슈 리포트/공유용).
   - 구현: zsh preexec/precmd로 마지막 블록 범위 기록 → `pbcopy`. 난이도: **중간** (출력 캡처 한계 동일).

6. **[낮음] config draft 적용** — 이미 검증된 즉시 이득.
   - `window-save-state=always`(세션 연속성), `theme=dark/light`(OS 연동), `clipboard-read=allow`(마찰 제거). draft에 검증 완료. 코드 변경이라 본 에이전트 범위 밖 — 사용자/coder가 적용.
