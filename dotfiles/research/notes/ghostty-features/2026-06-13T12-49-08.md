## 핵심 발견

현재 툴킷은 "스크립트 우선" 접근이라, Ghostty 1.x 가 네이티브로 제공하는 다음 기능들을 거의 안 쓰고 있음.
아래는 **네이티브로 한 줄이면 되는데 현재 미사용**인 항목들.

### A. 창/탭/스플릿 관리 (가장 큰 공백)
- 현재 splits/탭 keybind가 **전혀 없음**. Ghostty는 네이티브 split을 강력하게 지원.
  - `keybind = cmd+d=new_split:right`, `cmd+shift+d=new_split:down`
  - `keybind = cmd+alt+arrow=goto_split:...`, `cmd+shift+enter=toggle_split_zoom`
  - `keybind = cmd+ctrl+arrow=resize_split:...`
  - 워크플로: tmux 없이도 네이티브 분할 → broadcast input 기능과도 시너지.

### B. 키보드 기반 텍스트 선택/스크롤백 점프 (`jump_to_prompt`)
- Ghostty는 shell integration 기반 **프롬프트 점프**를 네이티브 지원.
  - `keybind = cmd+up=jump_to_prompt:-1`, `cmd+down=jump_to_prompt:1`
  - 워크플로: 긴 빌드 로그에서 이전 명령 출력 시작점으로 즉시 이동. Line Timestamps 기능과 궁합 좋음.

### C. 빠른 스크롤백 검색 / 화면 내보내기 보완
- `keybind = ...=write_scrollback_file:...` — 현재 write_screen_file(화면)만 있고 **전체 스크롤백 덤프**는 미사용.
  - 예: `keybind = cmd+shift+s=write_scrollback_file:paste` (긴 로그 전체를 에디터/파일로).

### D. 설정 자체 워크플로
- `keybind = cmd+comma=open_config`, `cmd+shift+comma=reload_config` — 미사용.
  - 워크플로: 1인 유지보수 시 config 빠른 수정·핫리로드. (이 툴킷은 config를 자주 만짐.)

### E. 표면/세션 편의 액션
- `keybind = ...=toggle_tab_overview` (GTK) / macOS 탭 네비게이션 `cmd+1..9=goto_tab:N` — 미사용.
- `keybind = ...=copy_url_to_clipboard`, `...=toggle_window_decorations` 등.

### F. config 옵션 (keybind 외)
- `clipboard-read = allow` / `clipboard-write = allow` — 이미지·텍스트 paste 워크플로 신뢰성 ↑ (현재 prompt 뜰 수 있음).
- `clipboard-paste-protection` / `clipboard-paste-bracketed-safe` — 멀티라인 paste 사고 방지.
- `confirm-close-surface = false` (또는 true 유지) — split 다용 시 UX 결정.
- `window-save-state = always` — 재시작 시 세션 복원. (워크플로 연속성)
- `quick-terminal-animation-duration`, `quick-terminal-position` — 이미 quick terminal 쓰므로 튜닝 여지.
- `mouse-hide-while-typing = true`, `window-padding-balance = true`, `cursor-style-blink` 등 미세 UX.
- `link-url = true` 및 커스텀 `link` regex — 로그 속 경로/이슈번호 클릭 가능하게.
- `font-feature`, `adjust-cell-height` 등 가독성 옵션 (지식 작업 多 → 가치 있음).

### G. theme / 외관 자동화
- `theme = dark:<x>,light:<y>` — macOS 라이트/다크 자동 전환. (Profile Auto-Switch 는 SSH용 배경만 처리 — OS 테마 연동은 별개 공백.)

## 이 툴킷에 추가할 제안 (우선순위순)

1. **[높음] 네이티브 split + 탭 keybind 세트** — 현재 완전 공백. tmux 의존 없이 멀티팬 워크플로 제공, 기존 broadcast input과 직접 시너지. 구현: `config/ghostty` 에 keybind 블록 추가. 난이도: 낮음 (순수 config). Ghostty 네이티브 ✅.

2. **[높음] `jump_to_prompt` 프롬프트 점프 + `write_scrollback_file`** — Line Timestamps/로그 워크플로와 결합 시 "긴 빌드 로그 항해" 경험 차별화. 구현: keybind 2~3줄. 난이도: 낮음. 네이티브 ✅ (shell integration 이미 활성).

3. **[높음] clipboard 신뢰성 옵션** — `clipboard-read/write = allow`, paste protection. 이미지 paste(이 툴킷 핵심 기능)의 권한 prompt 제거 → UX 마찰 감소. 구현: config 2~3줄. 난이도: 낮음. 네이티브 ✅. (보안 trade-off 사용자 확인 권장.)

4. **[중간] OS 테마 자동 전환 `theme = dark:...,light:...`** — Profile Auto-Switch(SSH 배경)와 별개로 라이트/다크 자동화. 구현: config 1줄. 난이도: 낮음. 네이티브 ✅.

5. **[중간] config 워크플로 keybind** (`open_config`/`reload_config`) — 1인 유지보수 효율. 핫리로드로 실험 빠르게. 난이도: 낮음. 네이티브 ✅.

6. **[중간] `link` 커스텀 regex** — 로그 속 파일경로/이슈번호/URL 클릭 가능. 기존 triggers/timestamps 와 같은 "터미널 = 작업 허브" 방향성. 난이도: 중간(regex 설계). 네이티브 ✅.

7. **[낮음] `window-save-state = always` 세션 복원** + 미세 UX 옵션(mouse-hide, padding-balance, cursor blink). 구현: config 줄 추가. 난이도: 낮음. 네이티브 ✅.

> ⚠️ 검증 필요: 위 keybind 액션명/옵션명은 지식(cutoff 2026-01) 기준. 실제 적용 전 `ghostty +list-keybinds` / `ghostty +show-config --default` / ghostty.org/docs/config 로 정확한 액션 문법(`new_split:right` vs `right` 등 버전별 차이) 확인 권장. (이번 사이클은 예산 제약으로 라이브 웹 검증 미완.)
